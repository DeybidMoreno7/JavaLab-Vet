# Archivo plano de referencia para anotar el planteamiento de la solución
Las clases Ave, Perro y Gato heredarán de la clase abstracta Animal, 
pues bien, Animal es lo que mejor abstrae el concepto que engloba a
las 3 clases.

A priori creo que la "consulta con costo" puede ser un método default
en una Interface.

No entendí inicialmente cómo pasar a código el tema de vacunado y asegurable,
creo que serían Interfaces también.

La ficha técnica podría ser un método de la clase Animal que las clases
hijas sobreescriban con super y concatenen con el costo de su consulta.
